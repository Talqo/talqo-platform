# Improved Landing Page Design

## Essence

Keep the current hero message because it is direct and descriptive. Improve the page around it so visitors quickly understand:

- Talqo embeds with one small script.
- The widget works on real business sites.
- The landing page has a live widget in the bottom-right corner, so users can try it immediately.

## Direction

Use a refined dark editorial hero: code snippet, website mockup, and a subtle cue toward the real widget. Follow it with short visual sections, not long marketing copy.

## Content

- Hero: existing headline/description, stronger visual proof.
- Setup strip: Copy → Paste → Chat.
- Use cases: Shop, SaaS/docs, Services.
- Capability chips: knowledge base, MCP tools, brand colors, rate limits, analytics, any website.
- CTA: start free; mention trying the widget in the corner.

## Constraints

- Keep all strings translated in English, Czech, and Chinese.
- Keep layout responsive and keyboard accessible.
- Do not change requirement completion status; this is a marketing/UI improvement for already implemented widget requirements.
