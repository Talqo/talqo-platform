### Task 10: Fix Tool Stability (Compare by Key, Not Translated Name)

**Files:**
- Modify: `apps/web/src/data/tools.ts`
- Modify: `apps/web/src/data/tools.ts` (Tool type — add `key` field)
- Modify: `apps/web/src/components/settings/ToolsTab.tsx`
- Modify: `apps/web/src/components/tools/UsedToolItem.tsx`

**Problem:**
- `Tool` type has `id`, `name`, `description`, `color`, `icon`
- `name` is translated via `t("tools.toolNames.productDatabase")`
- `isToolAdded(toolName)` compares `tool.name === toolName` which breaks on language switch
- `getToolDescription(name, t)` matches by translated `name.includes(...)` which also breaks

**Solution:**
Add a stable `key` field to the `Tool` type (e.g. `"productDatabase"`), pass it through creation functions, and use it for identity checks.

**Steps in `data/tools.ts`:**

```typescript
export type Tool = {
	id: string
	key: string    // <-- add this
	name: string
	description?: string
	color: "blue" | "green" | "purple" | "red" | "yellow"
	icon: string
}
```

Update `getDefaultUsedTools` and `getPreconfiguredTools` to include `key` from source arrays.

Update `getToolDescription(name, t)` to `getToolDescription(key: string, t)` and match against keys:

```typescript
export function getToolDescription(
	key: string,
	t: (key: string) => string,
): string {
	if (key === "productDatabase")
		return t("tools.toolDescriptions.readOnlyConnector")
	if (key === "customKnowledgeBase")
		return t("tools.toolDescriptions.staticFallbackInfo")
	return t("tools.toolDescriptions.toolConnector")
}
```

**Steps in `ToolsTab.tsx`:**
- Change `isToolAdded(toolName: string)` to `isToolAdded(tool: Tool)` or compare by `tool.key`
- Change `pendingToolNames` to `pendingToolKeys`
- Change `usedTools.some((tool) => tool.name === toolName)` to `usedTools.some((tool) => tool.key === tool.key)`
- When animating, use `tool.key` for tracking

```typescript
const isToolAdded = useCallback(
	(tool: Tool) =>
		usedTools.some((t) => t.key === tool.key) ||
		pendingToolKeys.has(tool.key),
	[usedTools, pendingToolKeys],
)
```

**Steps in `UsedToolItem.tsx`:**
- Change `getToolDescription(tool.name, t)` to `getToolDescription(tool.key, t)`
